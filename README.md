# Terraform Learning Journey 🚀

## About This Repository
This repository documents my Terraform learning journey, including theory notes, hands-on exercises, and interview-focused revision material. The goal is to build a strong understanding of Infrastructure as Code (IaC) concepts while maintaining concise notes for quick revision.

---
## Why I Created This Repository
I realised that I understand and remember concepts much better when I write them down in my own words.

This repository serves as:
* My personal revision guide.
* A place to document hands-on learning.
* A collection of interview preparation notes.
* A way to share my learning journey with the community.

---
## Who Is This Repository For?
This repository may be useful for:
* Beginners starting with Terraform.
* DevOps and Cloud Engineers.
* SRE and Platform Engineers.
* Anyone preparing for Terraform interviews.
* Learners looking for concise and easy-to-understand notes.

---
## Learning Approach
I follow a simple approach:

📖 Learn the concept
🧪 Practice with hands-on labs
📝 Create short notes in my own words
🔄 Revise regularly and improve understanding
